# INS2053 Course Workspace

Cấu trúc thư mục chuẩn cho khóa học Web Authoring and Web Management.

## Mục đích
- Lưu bài tập trên lớp
- Lưu homework theo tuần
- Quản lý project cuối khoá
- Tạo nơi thực hành và nộp bài

## Cấu trúc chính
- `ebook/` - tài liệu học chính
- `slides/` - slide giảng dạy
- `canvases/` - giáo án tương tác
- `exercises/` - bài tập theo buổi
- `homework/` - homework theo buổi
- `exams/` - đề và đáp án
- `project/` - đồ án cuối khoá
- `examples/` - mẫu website tham khảo
- `references/` - tài liệu tham khảo
- `site/` - website công khai

## Cách dùng
1. Mỗi buổi học có thư mục `exercises/session-XX` và `homework/session-XX` tương ứng.
2. Lưu project của bạn trong `project/`.
3. Dùng `examples/student-club/` như tài liệu tham khảo.
4. Đặt file làm bài trong đúng session tương ứng.
